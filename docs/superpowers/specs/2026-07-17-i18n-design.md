# L-P5 i18n 国际化 (zh-CN + en-US) - 设计文档

> 状态：用户已确认设计
> 日期：2026-07-17
> 关联：DEVLOG.md L-P5，预估 3-4 天

---

## 1. 目标

为化疗血常规追踪器增加端到端国际化：前端 UI 全部可通过 i18next 切换 zh-CN（默认）/ en-US；后端不再为错误返回展示文本，而是发出稳定 `code`，前端把 `code -> 翻译文案`；审计日志 `detail` 迁移到同样的 `detailCode + detailParams` 模型（历史中文 `detail` 向后兼容）。语言偏好持久化到 `User.settings.language`（跨设备同步）+ `lang` localStorage key（即时、登录前）。

**不在范围内**：服务端按 `Accept-Language` 动态本地化（已决策走 error-code 模式，由前端翻译）、更多语种（架构预留，填 JSON 即可扩）、后端 success message 的 code 化（仅 error 路径）、历史审计日志中文 detail 的批量迁移（保留向后兼容）。

## 2. 用户决策汇总

| # | 问题 | 决策 |
|---|---|---|
| Q1 | 支持语种 | zh-CN（默认）+ en-US |
| Q2 | 后端字符串翻译深度 | 前端 i18n + 后端 error code（ApiError 加 `code`，前端映射；不走 Accept-Language） |
| Q3 | code 与 message 关系 | 两者都上线路；`code` 供前端映射，`message` 保留作双语/EN 兜底 + curl 调试 |
| Q4 | 审计日志 detail | 新增 `detailCode? + detailParams?`；旧 `detail` 原样回退（历史记录不迁移） |
| Q5 | 语言偏好持久化 | localStorage `lang`（手动覆盖标记）+ `User.settings.language`（跨设备） |
| Q6 | 校验错误结构 | 平行 `errorCodes: Record<field, code>` map；前端优先用 `errorCodes[field]` |
| Q7 | 限流消息 | 限流 message 对象内直接加 `code`（绕过 ApiError） |

## 6. 前端架构

### 6.1 i18n 配置 - `frontend/src/i18n/index.ts`（新增）

```ts
import i18next from 'i18next';
import { initReactI18next } from 'react-i18next';
import zhCN from './locales/zh-CN';
import enUS from './locales/en-US';

function detectLanguage(): string {
  const manual = localStorage.getItem('lang');
  if (manual === 'zh-CN' || manual === 'en-US') return manual;
  try {
    const u = JSON.parse(localStorage.getItem('user') || 'null');
    if (u?.settings?.language) return u.settings.language;
  } catch { /* ignore */ }
  return navigator.language?.startsWith('en') ? 'en-US' : 'zh-CN';
}

i18next.use(initReactI18next).init({
  resources: { 'zh-CN': zhCN, 'en-US': enUS },
  lng: detectLanguage(),
  fallbackLng: 'zh-CN',
  initImmediate: false,           // 同步初始化，测试必需
  interpolation: { escapeValue: false },
});

export default i18next;
```

资源文件按命名空间分域：`frontend/src/i18n/locales/{zh-CN,en-US}/{auth,common,layout,dashboard,bloodTest,chemoCycle,analytics,reminders,settings,share,myelosuppression,errors,audit}.json`（13 个）。组件 `useTranslation('bloodTest')` 限定作用域。

### 6.2 启动接入 - `frontend/src/index.tsx`

顶部 side-effect import：`import './i18n';`（在 `<App />` 之前）。无需 `<I18nextProvider>`，react-i18next 读单例。

### 6.3 语言切换器 - `frontend/src/components/Layout/LanguageSwitcher.tsx`（新增）

Layout header 常驻下拉 + Settings profile tab 内 `<select>`。切换时：
1. `i18n.changeLanguage(lg)`
2. `localStorage.setItem('lang', lg)`
3. 已登录则 `authService.updateSettings({ language: lg })`（fire-and-forget）

### 6.4 AuthContext 联动 - `frontend/src/context/AuthContext.tsx`

`login` / `refreshUser` 后，若 `user.settings.language` 与当前 i18n 不同且用户未手动覆盖（无 `lang` localStorage key），则 `i18n.changeLanguage(user.settings.language)`。

### 6.5 错误码翻译 - `frontend/src/services/api/errorMapper.ts`（新增）

```ts
import i18n from '../../i18n';
import { ApiError } from './apiClient';

export function translateApiError(error: unknown): string {
  if (error instanceof ApiError && error.code) {
    const key = `errors:${error.code}`;
    const t = i18n.getFixedT(null, 'errors');
    const msg = t(key, error.params ?? {});
    if (msg !== key) return msg;          // 命中翻译
  }
  return error instanceof Error ? error.message : 'Unknown error';
}

export function translateFieldError(error: unknown, field: string): string | undefined {
  if (error instanceof ApiError && error.errorCodes?.[field]) {
    const t = i18n.getFixedT(null, 'errors');
    const key = `errors:${error.errorCodes[field]}`;
    const msg = t(key);
    if (msg !== key) return msg;
  }
  if (error instanceof ApiError) return error.errors?.[field];
  return undefined;
}
```

`apiClient.handleError` 从任意错误响应形状（ApiError 抛出 OR 限流 plain object）读 `code`/`errorCodes`/`params`，附到抛出的 `ApiError`。组件调用 `translateApiError(err)` 替代 `err.message`，字段错误用 `translateFieldError(err, field)`。

### 6.7 本地化日期 - `frontend/src/utils/formatDate.ts`（新增）

import i18n from '../i18n';
export function formatDate(iso: string): string {
  return new Date(iso).toLocaleDateString(i18n.language);
}
export function formatDateTime(iso: string): string {

## 9. 风险

1. **医学翻译质量**：`myelosuppression.ts` 约 20 条化疗中性粒细胞减少临床指引，机翻有临床风险。结构化 JSON 便于复核，标记医学 key，Phase 6 关闭前需母语英语医学复核签字。
2. **46 测试选择器 + 同步 i18n**：`setupTests.ts` 仅在 i18n 以 zh-CN 同步初始化时修复全部选择器。`initImmediate: false` + 静态打包资源必需。Phase 3 先验证，再进 Phase 4。
3. **审计日志向后兼容**：旧日志中文 `detail` 在 en-US 模式仍显中文。接受（历史记录）而非冒险批量迁移医学/审计数据。
4. **契约 4 处同步**：加 `language` 涉及 contracts + 前端 types + 后端 model + validation。第 6 项 contract-validator 校验必须确认 4 处都含 `language`。Phase 1 必须先落地第 6 项。
5. **限流消息绕过 ApiError**：`app.ts` 4 个限流 message 是 plain object。直接在对象内加 `code`；`apiClient.handleError` 从任意错误响应形状读 `data.code`。
6. **校验 payload 膨胀**：平行 `errorCodes` map 增大校验错误 JSON。接受（替代方案「替换 errors 值为 code」破坏向后兼容）。
7. **重载语言闪烁**：`user.settings.language` 与 `localStorage['lang']` 不同时，i18n 先按 localStorage 加载，AuthContext mount 后可能切换。由 i18n init 读两个 flag 缓解（手动 `lang` 优先）；AuthContext 仅在显式不一致时 `changeLanguage`。
