# BloodTrack Miniapp（本地可测版）

uni-app（Vue 3 + TypeScript + Pinia）微信小程序客户端。

## 信息架构（底部 Tab）

| Tab | 页面 | 内容 |
|---|---|---|
| 首页 | `pages/home` | 概览、近期待办、最近血常规、快捷入口 |
| 记录 | `pages/records/calendar` | 月历与当日事件 |
| 趋势 | `pages/analytics` | 血常规/生化趋势图 |
| 我的 | `pages/mine` | 资料入口、各记录列表、账号安全、退出 |

右下角 **+**（各主 Tab 页）：加一笔半屏选择（血/生/化/提醒）。  
二级页（表单、列表详情）从 Tab 内 `navigateTo` 进入，不再全部堆在首页。

当前切片：

1. 邮箱注册 / 登录 + JWT 刷新  
2. 血常规列表 + 加一笔（创建）  
3. 统一账号：手机/邮箱互通注册与登录  
4. 生化检查、化疗周期列表 + 加一笔  
5. 提醒列表 + 加一笔（完成/删除/筛选）  
6. 简易月历（血常规/生化/化疗/提醒点位 + 当日列表）  
7. **趋势分析（血常规/生化折线 + 参考范围）**

## 前置条件

1. MongoDB 可用  
2. 后端已启动（**推荐本机 `PORT=5001`**，避开 macOS AirPlay 的 5000）

```bash
# 仅 Mongo（若用 Docker）
docker compose up mongo -d

# 后端（推荐 5001）
cd backend
PORT=5001 npm run dev
```

健康检查：

```bash
curl -s http://127.0.0.1:5001/api/health
```

## 代理 / 本地端口（重要）

当前若系统开了 HTTP/SOCKS 代理（例如端口 **10808**），请求 `localhost` / 部分本机端口可能被代理劫持或超时。

建议：

1. **API 地址用 `127.0.0.1`，不要用 `localhost`**（默认已如此）  
2. **代理绕过本机**：

```bash
# shell 临时
export NO_PROXY=127.0.0.1,localhost
export no_proxy=127.0.0.1,localhost

# Clash / 其他客户端：开启「绕过局域网 / 绕过中国大陆」或把 127.0.0.1 加入直连
```

3. 微信开发者工具：详情 → 本地设置 → **不校验合法域名、web-view、TLS…**  
4. 若仍失败：在开发者工具里看 Network，确认请求是否打到 `127.0.0.1:5001`，而不是代理 IP  

默认环境变量（`miniapp/.env.development`）：

```env
VITE_API_BASE_URL=http://127.0.0.1:5001/api
```

真机调试改为电脑局域网 IP，例如 `http://192.168.1.10:5001/api`，并保证手机与电脑同网、代理不拦截。

### macOS 5000 端口

「隔空播放接收器」常占用 **5000**。`curl` 若返回 403 且 `Server: AirTunes`，请换 `PORT=5001` 或关闭隔空播放接收器。

## 本切片验收路径

### 统一账号互通（Mock 短信）

```bash
cd backend
SMS_FIXED_CODE=123456 SMS_PROVIDER=fixed PORT=5001 npm run dev
```

| 场景 | 操作 |
|---|---|
| 手机注册 | 注册页「手机号」→ 验证码 → 自动建号 |
| 设密码后手机密码登录 | 首页 → 账号与安全 → 设置密码 → 登录页「密码登录」填手机号 |
| 绑定邮箱 | 账号与安全 → 绑定邮箱（同时设/验证密码）→ 可用邮箱+密码登录 |
| 邮箱注册 | 注册页「邮箱」→ 邮箱+密码 |
| 绑定手机 | 账号与安全 → 绑定手机（验证码 purpose=bind）→ 可用手机+密码或验证码登录 |
| 换绑手机 | 账号与安全 → 填新号验证码 +（密码或原号验证码） |
| 换绑邮箱 | 账号与安全 → 新邮箱 + 当前密码 |
| 解绑手机 | 须已绑定邮箱且有密码；确认密码后解绑 |
| 解绑邮箱 | 须已绑定手机；确认密码后解绑 |

登录页：

- **验证码登录**：仅手机 + SMS（未注册则自动注册）  
- **密码登录**：手机号 **或** 邮箱 + 密码（`account` 字段自动识别）
